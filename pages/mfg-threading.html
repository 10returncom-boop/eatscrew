    攻牙 / 車螺紋 Cutting

    概述

    切削牙，小批量或大件。攻牙 / 車螺紋（Cutting）是螺絲的螺紋型式，定義了牙距、牙型角、公差等級與適用的對手孔。螺紋選擇直接影響鎖付強度、密合性與互換性。

    關鍵參數

    • 公稱直徑：螺紋外徑，如 M6 代表公稱 6mm。
    • 牙距 P：相鄰牙峰距離。粗牙（Coarse）通用；細牙（Fine）防鬆、精確度高。
    • 公差：外螺紋 6g、內螺紋 6H 是最通用的通用級。
    • 導程角：決定自鎖性與鬆動傾向，導程角越小越不易自轉鬆脫。

    應用場景

    • 一般機械與電子 → 公制粗牙 M。
    • 薄壁件與高壓油管 → 細牙或管牙。
    • 塑膠與鈑金 → 自攻牙或鑽尾牙，免預攻牙。
    • 美系設備 → UNC（粗）/ UNF（細）英制螺紋。
    • 半導體、醫療 → 微型螺紋 M0.6–M1.6。

    選用建議

    • 一般組裝優先選粗牙，拆裝容易、耐髒。
    • 需防鬆或薄壁鎖付 → 細牙。
    • 塑膠件 → 選專用塑膠牙（PT/BT），避免破裂。
    • 對接美系產品 → 確認 UNC/UNF 而非公制。
